# Internal planning documents

These are the planning documents and agent briefs the team wrote while building Veil during NEAR HACKATHON. They are kept for transparency.

They describe plans, rules and drafts, not shipped features. Some planned items were cut. For example, the brief's NEAR Intents demo, encrypted memos, FT sends in the web app and a separate explorer view were not built. What Veil actually does is described in the [top-level README](../../README.md) and checked by the tests and evidence linked there.

| File | What it is |
|---|---|
| `VEIL-BRIEF.md` | The original build brief for the coding agent |
| `COMMON-RULES.md` | Rules shared by the team's hackathon projects |
| `execution/` | The task ledger and handoff notes from the build |
| `design/` | The product requirements draft and design reference sheet |
| `X-DRAFT.md` | Draft text for the X post |
