# Veil reference sheet

| Reference | Take | Veil decision |
|---|---|---|
| Ontiver | Trust details close to actions; plain copy | Put testnet status, key handling and public limits beside the wallet flow |
| QuickBite | Clear numbered progression and restrained motion | Use numbered flow labels and short state transitions |
| Nothin' | Strong type on a quiet canvas | Let typography and spacing carry the page; no decorative gradients |
| Trustly travel | One clear benefit and proof at decision points | Keep wallet and network proof visible in the header and hero |
| Vectura | Named, inspectable contact information | Show registry/router IDs and NearBlocks links as inspectable evidence |
| ERC-5564 | Explicit stealth address vocabulary | Use precise names: meta-address, announcement, view key and spend key |
| NEAR wallet UX | Wallet approval is a critical transition | Preserve visible status and error output after every wallet action |
| NearBlocks | Public history is the comparison surface | Keep explorer comparison as an explicit read-only action |

The product is a fintech privacy tool, so trust and state clarity take priority over decorative effects. The existing static architecture is retained for bundle size and wallet integration stability.
