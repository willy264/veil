# Demo Video Script

The recording uses the production web build against live testnet data and the voiceover generated by `scripts/generate-voiceover.ps1`. The exported MP4 is `results/veil-demo.mp4` (generated locally and ignored by Git because it is a binary artifact). Upload that file to Clipdio or another editor, then use the generated voiceover track if a separate narration track is needed. The script is intentionally evidence-led: it does not simulate wallet signatures or claim that a headless browser owns Alice's keys.
